# Телефонен указател (C# / .NET 10 / WPF / SQLite)

## Стартиране
Visual Studio 2026: отворете `PhoneBook.csproj` и натиснете F5.
Команден ред (в папката на проекта):
```
dotnet run
```
Базата `contacts.db` се създава автоматично при първо стартиране и се попълва с 6 примерни контакта.
Анимациите и темите са с чист WPF (Storyboard, RenderTransform) – без допълнителни NuGet пакети.

## Теми
- По подразбиране приложението е **тъмно**.
- Бутонът с **луна / слънце долу вляво** сменя темата. Новата тема се разкрива с разширяващ се кръг от бутона, а иконата се завърта и сменя.
- Изборът се запомня в `theme.txt` до програмата.
- Заглавната лента на Windows също става тъмна (Windows 10 20H1+). На Windows 11 приема и точния цвят на фона.
- Всички цветове се ползват с `{DynamicResource}`, затова целият интерфейс се сменя на живо.

## Анимации
Анимират се само `Opacity`, `RenderTransform` и `SolidColorBrush.Color` → плавни 60 fps без преизчисляване на layout.

| Анимация | Кога | Детайли |
|---|---|---|
| Входна каскада | При отваряне | Горна лента → лява карта → дясна карта (+0.08 s) → долна лента; `Y 16 → 0`, `Opacity 0 → 1`, CubicEase |
| Бутони | Посочване / натискане | Мащаб 1.025 и плавно преливане на цвета (0.12 s); при натискане 0.96 (0.07 s) |
| Филтър-хапчета | Посочване / избор | Леко уголемяване, плавно преливане на фона и на „избраното“ състояние |
| Полета | Фокус | Плавно появяване на акцентна рамка и мек „пръстен“ |
| Валидация | Грешно поле | Поклащане на полето (−7, 7, −5, 5, −2, 0 за 0.30 s) + плавно появяване на червената лента |
| Редактор | Избор на контакт / „Нов“ | Плъзгане `X 10 → 0`, `Opacity 0.65 → 1` за 0.20 s |
| Редове в таблицата | Филтър / търсене / зареждане | Каскадно появяване (по 22 ms между редовете) |
| Записан ред | След добавяне / запис | Кратко зелено оцветяване, което избледнява |
| Toast | Добавяне / запис / изтриване | Хапче долу в средата изплува, стои 1.6 s и изчезва |
| Брояч | Промяна на броя | Леко „подскачане“ |
| Изтриване | „Изтрий“ | Бутонът става червен „Потвърди“ за 3 s; второ натискане изтрива |
| ComboBox | Отваряне | Стрелката се завърта на 180° |

## Интерфейс
- **Горна лента:** икона, заглавие, брояч на контактите и поле за търсене.
- **Таблица:** кръгъл аватар с инициали, име, телефон, имейл и цветен етикет на групата.
- **Филтър:** хапчета Всички / Семейство / Работа / Приятели / Други.
- **Редактор:** преглед на живо (аватар, име, телефон, група), поле „Група“ с цветни точки, бутони Добави/Запази, Нов и Изтрий.
- **Долна лента:** бутон за тема (луна/слънце) вляво.
- Няма изскачащи прозорци: грешките са в червена лента във формата, успехът е в toast, изтриването се потвърждава с второ натискане.

## Таблица
```sql
CREATE TABLE Contacts (
    Id        INTEGER PRIMARY KEY AUTOINCREMENT,
    Name      TEXT NOT NULL,
    Phone     TEXT NOT NULL,
    Email     TEXT,
    GroupName TEXT NOT NULL
);
```

## Валидация
- **Име:** задължително, поне 2 символа.
- **Телефон:** задължителен; цифри, интервали, `-`, `()` и `+` в началото; поне 6 цифри.
- **Имейл:** не е задължителен, но ако е попълнен, се проверява форматът.
